# Лендинг Елены Свердловой

Статический адаптивный лендинг без сборки. Подходит для Vercel, Netlify, Cloudflare Pages, GitHub Pages и обычного хостинга.

## Запуск

Откройте `index.html` напрямую или запустите локальный сервер:

```powershell
npx serve .
```

## Контакты и бесплатный разбор

В `site-config.js` укажите подтверждённую ссылку Елены в поле `telegramUrl`. Пока оно пустое, кнопки записи ведут в Instagram и показывается предупреждение для владельца сайта. Бесплатный разбор уже направлен в `https://t.me/bazovyi_kod_bot`.

Онлайн-оплата в текущую версию не включена: по ТЗ она предусмотрена как следующий этап. Сайт не принимает и не хранит реквизиты карты.

## Что заменить перед публикацией

- Подтверждённую ссылку Telegram и юридические реквизиты.
- Исходные фотографии без рекламных надписей и финальный логотип.
- Реальные отзывы — только после разрешения авторов.
- Политику конфиденциальности под страну работы.
- Фото взяты из публичного Instagram-профиля Елены для макета. Перед коммерческой публикацией подтвердите право использования и при необходимости замените оригиналами высокого разрешения.
