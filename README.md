# Лендинг Елены Свердловой

Статический адаптивный лендинг без сборки. Подходит для Netlify, Cloudflare Pages, GitHub Pages и обычного хостинга.

## Запуск

Откройте `index.html` напрямую или запустите локальный сервер:

```powershell
npx serve .
```

## Подключение оплаты

1. Создайте продукты и платёжные ссылки в выбранном сервисе: Stripe, WayForPay, LiqPay, Fondy и т. п.
2. Вставьте URL в `site-config.js` напротив нужной услуги.
3. Пока ссылка пустая, кнопка корректно переводит клиента к форме заявки.

Сайт не принимает и не хранит реквизиты карты: оплата должна проходить на странице платёжного провайдера.

## Форма заявок

Форма уже размечена для Netlify Forms. После публикации на Netlify заявки появятся в разделе Forms. На другом хостинге подключите свой endpoint в `script.js`.

## Что заменить перед публикацией

- Финальные тексты, состав и длительность услуг.
- Цены и платёжные ссылки.
- Контактные каналы и юридические реквизиты.
- Политику конфиденциальности под страну работы.
- Фото взяты из публичного Instagram-профиля Елены для макета. Перед коммерческой публикацией подтвердите право использования и при необходимости замените оригиналами высокого разрешения.
